# User commands

> Generated by `lib.nvim.usercmd.composer`. Do not edit by hand.

## :Sandbox

sandbox.nvim: container, image, volume, network, compose, and WSL distro operations (Docker/Podman)

| Invocation | Description |
| --- | --- |
| `:Sandbox compose down` | Stop and remove the compose project detected in cwd |
| `:Sandbox compose logs` | Show logs for the compose project detected in cwd |
| `:Sandbox compose ps` | List services in the compose project detected in cwd |
| `:Sandbox compose restart` | Restart the compose project detected in cwd |
| `:Sandbox compose up` | Start the compose project detected in cwd (detached) |
| `:Sandbox container cp {src} {dest}` | Copy a file/directory between the host and a container (either side may be <id>:<path>) |
| `:Sandbox container exec {id:CONTAINER_ID} [{shell}]` | Open a shell session inside a running container |
| `:Sandbox container exec-once {id:CONTAINER_ID} [{command}]` | Run a one-off command inside a container (non-interactive) |
| `:Sandbox container inspect {id:CONTAINER_ID}` | Inspect detailed information about a container |
| `:Sandbox container kill {id:CONTAINER_ID} [--buffer|-b]` | Force kill a container (--buffer: stream to a terminal buffer) |
| `:Sandbox container list` | List all containers |
| `:Sandbox container logs {id:CONTAINER_ID}` | Show logs of a container |
| `:Sandbox container logs-follow {id:CONTAINER_ID}` | Stream a container's logs live (press q in the buffer to stop) |
| `:Sandbox container pause {id:CONTAINER_ID}` | Pause a running container's processes |
| `:Sandbox container prune [--buffer|-b]` | Remove all stopped containers (--buffer: stream to a terminal buffer) |
| `:Sandbox container remove {id:CONTAINER_ID} [--buffer|-b]` | Remove a stopped container (--buffer: stream to a terminal buffer) |
| `:Sandbox container rename {id:CONTAINER_ID} {new_name}` | Rename a container |
| `:Sandbox container restart {id:CONTAINER_ID} [--buffer|-b]` | Restart a container (--buffer: stream to a terminal buffer) |
| `:Sandbox container run` | Interactively create and start a new container (prompts for image, name, ports, volumes, env) |
| `:Sandbox container start {id:CONTAINER_ID} [--buffer|-b]` | Start a stopped container (--buffer: stream to a terminal buffer) |
| `:Sandbox container stats {id:CONTAINER_ID}` | Show a one-shot resource usage snapshot of a container |
| `:Sandbox container stop {id:CONTAINER_ID} [--buffer|-b]` | Stop a running container (--buffer: stream to a terminal buffer) |
| `:Sandbox container top {id:CONTAINER_ID}` | List the processes running inside a container |
| `:Sandbox container unpause {id:CONTAINER_ID}` | Resume a paused container's processes |
| `:Sandbox docs generate` | Regenerate docs/GENERATED_COMMANDS.md from the live route table, so docs/BINDINGS.md (hand-maintained) can be diffed against it to catch drift |
| `:Sandbox engine get` | Show the currently active engine and why |
| `:Sandbox engine reset` | Clear the session engine override, falling back to .sandboxrc/config |
| `:Sandbox engine set {name}` | Switch the active engine for this session |
| `:Sandbox image build {tag} [{path}]` | Build an image from a Dockerfile/Containerfile (streams to a terminal buffer) |
| `:Sandbox image history {image:IMAGE_ID}` | Show an image's layer history |
| `:Sandbox image inspect {image:IMAGE_ID}` | Inspect detailed information about an image |
| `:Sandbox image list` | List all local images |
| `:Sandbox image load {path}` | Load (import) an image from a tarball on disk |
| `:Sandbox image prune [--buffer|-b]` | Remove all dangling images (--buffer: stream to a terminal buffer) |
| `:Sandbox image pull {name} [--buffer|-b]` | Pull an image (--buffer: stream to a terminal buffer) |
| `:Sandbox image push {name}` | Push an image to a remote registry |
| `:Sandbox image remove {id:IMAGE_ID}` | Remove a local image |
| `:Sandbox image save {image:IMAGE_ID} {path}` | Save (export) an image to a tarball on disk |
| `:Sandbox image tag {source:IMAGE_ID} {target}` | Tag a local image with a new repository:tag |
| `:Sandbox network connect {network:NETWORK_NAME} {id:CONTAINER_ID}` | Connect a container to a network |
| `:Sandbox network create {name}` | Create a new named network |
| `:Sandbox network disconnect {network:NETWORK_NAME} {id:CONTAINER_ID}` | Disconnect a container from a network |
| `:Sandbox network inspect {name:NETWORK_NAME}` | Inspect detailed information about a network |
| `:Sandbox network list` | List all local networks |
| `:Sandbox network prune` | Remove all unused networks |
| `:Sandbox network remove {name:NETWORK_NAME}` | Remove a network |
| `:Sandbox registry login [{registry}]` | Log in to a registry (prompts for username/password) |
| `:Sandbox registry logout [{registry}]` | Log out of a registry |
| `:Sandbox volume create {name}` | Create a new named volume |
| `:Sandbox volume inspect {name:VOLUME_NAME}` | Inspect detailed information about a volume |
| `:Sandbox volume list` | List all local volumes |
| `:Sandbox volume prune` | Remove all unused volumes |
| `:Sandbox volume remove {name:VOLUME_NAME}` | Remove a volume |
| `:Sandbox wsl exec {name:DISTRO_NAME} [{command}]` | Open a shell or run a command inside a WSL distro |
| `:Sandbox wsl export {name:DISTRO_NAME} {path}` | Export a distro to a tarball on disk |
| `:Sandbox wsl import {name} {install_path} {tar_path}` | Import a distro from a tarball |
| `:Sandbox wsl list` | List all registered WSL distributions |
| `:Sandbox wsl set-default {name:DISTRO_NAME}` | Set a distro as the WSL default |
| `:Sandbox wsl set-version {name:DISTRO_NAME} {version}` | Toggle a distro between WSL1/WSL2 |
| `:Sandbox wsl shutdown-all` | Shut down the WSL2 VM and all running distros |
| `:Sandbox wsl start {name:DISTRO_NAME}` | Start a WSL distro |
| `:Sandbox wsl stop {name:DISTRO_NAME}` | Stop (terminate) a WSL distro |
